03Reglas rápidas para replicarlo en Canva
Do
  • Usa fondos oscuros: #2A1208 o #130A04.
  • Usa Cormorant Garamond para títulos elegantes.
  • Usa DM Sans para bullets y explicaciones.
  • Usa DM Mono para números, KPIs, tags y métricas.
  • Agrega bordes dorados delgados en cards y screenshots.
  • Usa dorado solo para acentos, no para todo el texto.
Avoid
  • No uses fondos blancos en secciones principales.
  • No mezcles más de estas tres familias tipográficas.
  • No pongas mucho texto en la diapositiva; deja el detalle como speaker note.
  • No uses tablas extensas; convierte datos en cards o gráficas.
  • No satures con dorado; úsalo para jerarquía visual.
  • No hagas los bullets más pequeños de 16 pt.
